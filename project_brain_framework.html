Como Iniciar com o Framework & Governança

Passo a passo prático para disparar a primeira demanda, seguido pelas diretivas de governança, lista de especialistas e o fluxo operacional com retroalimentação viva.

1

Prepare o Ambiente

Com o PROJECT-BRAIN.md já posicionado na raiz do repositório:

• Terminal (MIA): Faça mia login e abra com mia launch claude.
• VS Code: Abra o chat do GitHub Copilot na IDE.

2

Dispare a Demanda

Copie e envie o comando inicial com o card ou objetivo:

Terminal CLI (MIA) 
/start-demand <CARD>
VS Code Copilot 
@PROJECT-BRAIN.md iniciar demanda <CARD>
3

Deep Explore Dinâmico

O agente conduz perguntas dinâmicas (sem congelar a sessão) para investigar a arquitetura e sintetizar especialistas sob medida para o seu projeto.

4

Trava Pré-Código [A]

O Opositor Crítico (Marcus) debate o plano com os especialistas. Nenhum arquivo é editado até você responder formalmente [A] Aprovar plano.

Nunca Commit Automático

Git é restrito a leitura e staging cirúrgico pré-aprovado. Proibido git push sem ordem direta.

Trava Pré-Código

Zero edições antes de plano aprovado em turno explícito: Coleta ➔ Explore ➔ Roda ➔ Plano ➔ [A].

Zero Dump de Logs

Dumps e logs volumosos são processados no sandbox local. Respostas enxutas apenas com métricas e causas raiz.

Qual Launcher Utilizar? (Matriz de Ferramentas)

O MIA não se limita ao Claude. Execute o comando ideal para cada tipo de tarefa:

mia launch claude

O Carro-Chefe (Padrão)

Ideal para tarefas complexas de ponta a ponta, Clean Architecture, Roda de Personas e refatorações multi-arquivo.

mia launch codex

Assistente Rápido + Web

Assistente leve de código focado em edições rápidas com componente de busca web corporativa (web-search) ativo.

mia launch copilot

CLI Oficial Copilot

Usa o cliente oficial de linha de comando do GitHub Copilot integrado ao gateway corporativo LiteLLM.

mia launch pi / omp

Ultra-Leve & Terminal

Perguntas rápidas de terminal, scripts de shell, dúvidas pontuais sem gastar cotas ou janelas móveis pesadas.

mia launch open-design

Frontend & Design System

Especializado em tokens visuais, componentes de UI, CSS modular e alinhamento com design systems.

mia launch opencode

Multi-Tool Aberto

Runner aberto com suporte a ferramentas customizadas, scripts locais e integrações de repositório.

Tiers de Modelos (MIA_MODEL)

O MIA ajusta o LLM via variável de ambiente antes de abrir o cliente:

  • labs-code (Padrão): Uso diário, ótimo balanço custo/eficiência.
  • MIA_MODEL=labs-code-max: Para decisões arquiteturais densas, segurança e novos esquemas.
  • MIA_MODEL=labs-code-mini: Super econômico para commits, formatação e testes rápidos.

Comandos Essenciais do MIA

  • mia login: Autenticação Google corporativa (válida por ~7 dias).
  • mia quota: Monitora gastos do ciclo, cotas justas e janelas móveis de 2h/24h.
  • mia doctor: Diagnostica status do proxy, LSPs, RTK e versões instaladas.
  • mia tools list: Lista componentes e ativa/desativa LSPs (pyright, typescript).
  • mia plugin install: Instala skills e agents corporativos homologados.
