PROJECT BRAIN Framework

Enterprise Brain Framework — Sistema Operacional Single-File para orquestrar agentes de IA em qualquer repositório

Como Iniciar a Primeira Conversa

Siga estes 4 passos simples para ativar o agente de IA com governança rígida, sem risco de alterações indesejadas no seu repositório.

1

Prepare seu Ambiente

Terminal (MIA): Faça mia login e abra o agente com mia launch claude.
VS Code: Certifique-se de que o PROJECT-BRAIN.md está na raiz do projeto e abra o chat do Copilot.

2

Envie o Comando de Abertura

Dispare a demanda informando o código da tarefa (ex: STK-1234 ou nome da feature). Copie os comandos prontos logo abaixo.

3

Questionário & Trava Pré-Código

O agente analisa o escopo e apresenta o plano com o Opositor Crítico. Nenhum arquivo é editado até você responder [A].

4

Execução Cirúrgica & Validação

Após seu [A], o agente edita o código estritamente necessário e roda a Tríade Determinística: rtk test ➔ rtk eslint ➔ rtk build.

Comandos Prontos para Copiar

Opção A: No Terminal via Claude Code CLI (MIA): 

iniciar demanda <CODIGO_CARD> seguindo @PROJECT-BRAIN.md
# ou simplesmente:
/start-demand <CODIGO_CARD>

Opção B: No VS Code Copilot Chat: 

@PROJECT-BRAIN.md iniciar demanda <CODIGO_CARD>
# ou comando rápido:
/start-demand <CODIGO_CARD>
Trava Pré-Código Inegociável: O agente aguarda você digitar ou selecionar [A] Aprovar plano antes de criar ou modificar qualquer linha de código.

Governança & Personas Especialistas

O Brain garante qualidade industrial através de travas rígidas e deliberação circular entre 6 lentes técnicas + Opositor Crítico.

Nunca Commit Automático

Git é restrito a leitura (status/diff) e staging pré-aprovado. Proibido git push ou alterar histórico sem ordem direta.

Trava Pré-Código

Zero edições antes de plano aprovado em turno explícito. Fluxo: Coleta ➔ Explore ➔ Roda ➔ Plano ➔ [A] ➔ Código.

Zero Dump de Logs

Dumps e logs brutos ficam no sandbox local. Respostas enxutas apenas com métricas, causas raiz e deltas cirúrgicos.

RECOMENDADO CORPORATIVO

Enterprise (MIA-Native)

Trabalha em conjunto com o ecossistema MIA Luizalabs

Projetado especificamente para operar em simbiose com o MIA CLI (~/.mia/):

  • Proxy RTK integrado: filtra e compacta saídas no PATH, economizando de 60% a 90% dos tokens.
  • Gateway LiteLLM Corporativo: autenticação Google PKCE e quotas gerenciadas centralmente.
  • Context-Mode & LSPs: indexação inteligente em sandbox e LSPs semânticos STDIO (Go, Python, TypeScript).
  • Governança Enterprise: conformidade com SonarQube, Hangar, Netskope e cultura Luizalabs.
Baixar Enterprise (MIA-Native)

Salvar como PROJECT-BRAIN.md no repo corporativo.

Domestic (Uso Pessoal)

Edição portátil para estudos e projetos individuais

Projetado para ser 100% autônomo, sem qualquer dependência de rede corporativa:

  • Universal & Portátil: funciona com qualquer LLM (GitHub Copilot, OpenAI, Claude, Ollama, Cursor).
  • Sem Proxy Corporativo: não requer login PKCE, certificados CA ou ferramentas privadas.
  • Governança Local Simulada: mantém a Trava Pré-Código e aprovação [A] via prompts.
  • Ideal para Side-Projects: repositórios no GitHub pessoal, freelancers e estudos.
Baixar Domestic (Pessoal)

Pronto para uso individual ou comunitário.
