Pronto para Começar?

Como Instalar a GEM no Gemini

  1. Acesso Corporativo: Faça o login no Gemini Pro utilizando sua conta corporativa.
  2. Navegue até os Gems: No menu lateral esquerdo, clique em "Veja alguns Gems". Se o menu estiver recolhido, clique no ícone (☰) no canto superior esquerdo para expandi-lo.
  3. Crie uma Nova GEM: Na tela seguinte, procure e clique na opção para "Criar uma nova GEM".
  4. Dê um Nome: Defina um nome fácil de identificar, como "Arquiteto de Insights de Reunião" ou "Analisador de Meetings".
  5. Copie as Instruções: Utilize o botão "Copiar" na caixa de código abaixo para copiar todo o JSON da nossa GEM.
  6. Cole as Instruções: Cole o conteúdo copiado no campo principal de instruções da nova GEM.
  7. Salve: Clique para salvar as alterações. A partir de agora, sua GEM estará disponível no menu esquerdo, pronta para analisar suas reuniões!

Características Técnicas

Idioma

Toda comunicação em Português do Brasil (PT-BR), incluindo relatórios e gráficos.

Gráficos

Chart.js com escala forçada (0-5, stepSize 1) para evitar decimais confusos nos radares.

Neutralidade

Tom neutro e objetivo, baseando interpretações em evidências diretas da transcrição.

Completude

Análise mandatória de TODOS os participantes identificados, sem exceção.
